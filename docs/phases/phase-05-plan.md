# Phase 5 — PDF xref/layout proceduralization (subphase plan)

Goal: the first serious "document structure replaces literal observation" court.
Regenerate PDF structural bytes that are *determined by the materialized layout*
— cross-reference entry offsets and `startxref` — instead of storing them
literally, and store exact residuals only where prediction fails. Every
generated byte must remain source-exact.

Execution rules (frozen):
- All compilation/testing in the pinned Docker `dev` service; PDF oracles in
  `tools`. Never on host.
- Subphases in order; each: implement, test in Docker, commit, push to `phase5`.
- Subagents one at a time, disjoint files.
- A candidate is adopted only if byte-exact and strictly cheaper on complete
  serialized cost; otherwise it is recorded as a negative result.

## Subphases

| # | Subphase | Deliverable |
|---|---|---|
| 5.1 | Positional DRA ops | `MARK_OFFSET` / `EMIT_OFFSET` (v4): record an output position and emit it as zero-padded decimal of fixed width; bounded slots; universe → phase-5 |
| 5.2 | PDF layout builder | decompose a classic-xref PDF into a program that regenerates xref entry offsets and `startxref` from marked object positions, literal elsewhere, with per-site residual fallback; forced byte-exact |
| 5.3 | Structured candidate + court | integrate the layout candidate; forced ablation; compete vs RAW/RLE/BYTE_RANS/PDF_* |
| 5.4 | Corpus + measured ladder | classic-xref corpus; cumulative ladder + leave-one-out; record wins/losses honestly |
| 5.5 | Phase-5 evidence campaign | coverage/exactness, per-site prediction counts, residuals, latency, oracle re-check |
| 5.6 | Docs + freeze + merge | SPEC/PROJECT_STATE/README/CHANGELOG/ADR updated; merge `phase5` into `main` |

## Acceptance gates (predeclared)

1. **Exactness**: every accepted descriptor materializes byte-for-byte.
2. **Prediction correctness**: a regenerated offset equals the source offset, or
   that site falls back to a literal residual — never a wrong byte.
3. **Complete cost**: predicted structural bytes and residual metadata are fully
   charged; adoption requires a strict win.
4. **Honest result**: if structural prediction does not beat the best lane on the
   corpus, it is recorded (ADR), not hidden.
5. **Hostile-safe**: malformed PDFs never panic; prediction never invents bytes.
6. **Determinism**: identical input ⇒ identical descriptor bytes.
