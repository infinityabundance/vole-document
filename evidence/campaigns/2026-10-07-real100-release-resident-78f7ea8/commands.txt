# Result (honest): naive residency does NOT reduce repeated-observation lifetime
# cost on this corpus. VOLE resident wins only for documents below ~1 MiB; for
# 1-10MiB / 10-50MiB / 50-100MiB the cold lane is faster. Mechanism: the cold
# `observe` path takes `narrow_probe` — a per-call manifest + derived-cache
# short-circuit that returns the already-derived node without building the full
# evaluation context; `observe-batch` (v_r) always builds the full context, so
# its per-observation cost is higher even though it pays process spawn once.
