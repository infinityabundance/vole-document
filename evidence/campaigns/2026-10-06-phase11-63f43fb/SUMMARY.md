## Baselines (same machine, same run)

### A0 — raw PDF tooling (primary 33673730 B document)

- pdfinfo: 400 pages, max RSS 7892 kB.
- `pdftotext -f 1 -l 1`: 91 B text, wall 8 ms, **read/pread 136128 B** (467 calls), file mmap 31922563 B.
- `pdftotext` whole document: 35868 B, max RSS 8984 kB.
- `qpdf --linearize`: file 33676367 B, /E (end of first page) 84937 → first-page prefix fraction **0.002522**.

### A1 — preprocessed SQLite (fair: extraction charged in full)

- sqlite 3.40.1; extracted 400 pages with pdftotext in 1596 ms → DB 53248 B.
- page query: text 91 B, wall 1 ms, **read/pread 24393 B** (18 calls).
- **Recorded loss:** the indexed SQLite page lookup reads far fewer bytes than a VOLE `observe` (which reloads its full descriptor). A1 wins the narrow-query byte court; its one-time extraction and DB bytes are charged above.
